GET/POST /signup/ AJAX signup ▼

Description

AJAX-safe signup. Returns "true" on success or error string otherwise. Sends email activation link.

Headers Required

X-Requested-With: XMLHttpRequest

POST Parameters

FieldTypeRequired
usernamestringreq
emailstring (email)req
password1stringreq
password2stringreq

Response

// Success
"true"

// Error
"Username already taken"

Example (fetch)

const fd = new FormData();
fd.append('username', 'alice');
fd.append('email', 'alice@example.com');
fd.append('password1', 'secret123');
fd.append('password2', 'secret123');

fetch('/signup/', {
  method: 'POST',
  headers: {'X-Requested-With': 'XMLHttpRequest'},
  body: fd
}).then(r => r.text()).then(console.log);

POST /genai/api/pdf/process/ Process PDF → MCQs ▼

Description

Upload PDF → routes to task_router → generates MCQs/descriptive content and saves to DB.

Request (multipart/form-data)

FieldTypeRequiredDescription

subjectstringoptSubject name
task_typestringoptpdf_to_mcq (default)
difficulty_levelstringoptEasy | Medium | Hard
output_formatstringoptOutput format
num_itemsintoptNumber of items to generate
start_pageintoptStart page (default 1)
end_pageintoptEnd page

Response

  "task_id": "abc-123",
  "message": "Processing complete",

    "saved_items": 15
  }
}

Example (curl)

curl -X POST /genai/api/pdf/process/ \
  -F "pdf_file=@/path/to/chapter.pdf" \
  -F "subject=history" \

GET/POST /genai/admin/math-pdf-processing/<int:pk>/ Math PDF processing (GO button) ▼

Description

"GO button" form for configuring math PDF OCR + MCQ generation options. pk = MathProblemGeneration.id.

POST Fields (key ones)

FieldTypeDescription
extract_ruleboolWhen true, skips MCQ extraction and runs rule extraction instead
rule_numberstringe.g. Rule 1 … Rule 50 — which rule to save
pdf_prompt_idintOptional LLMPrompt ID to use for MCQ extraction
page_from / page_tointPage range to OCR

Auth

@staff_member_required

Example

GET  /genai/admin/math-pdf-processing/7/
POST /genai/admin/math-pdf-processing/7/  {extract_rule: true, rule_number: "Rule 1", ...}

Auth & CSRF Notes Important
INFO Authentication & CSRF Reference Key security notes ▼

CSRF

All /genai/api/ endpoints use @csrf_exempt — safe for external POST calls from non-browser clients (curl, Postman, etc.).

Authentication Decorators

DecoratorUsed OnBehavior on Failure
@staff_requiredGenAI admin viewsReturns JSON {"error": "Forbidden", "code": 403}
@staff_member_requiredSome GenAI + all bank admin viewsRedirects to /admin/login/
@login_requiredAll students app endpointsRedirects to /accounts/login/
NoneBank public pages, GenAI JSON APIs, MockTest APIsAccessible without login

Bank AJAX Note

Bank AJAX views (/add/, /del/, /login/, /signup/) check request.is_ajax(). They require the X-Requested-With: XMLHttpRequest header and return plain HttpResponse text — not JSON.

Only JSON-returning Bank Endpoint

/math/translate/<int:math_id>/<str:lang>/ is the only bank endpoint that returns a proper JsonResponse.

File Upload

/genai/api/pdf/process/ requires Content-Type: multipart/form-data, not application/json.
